# Лабораторная № 3

Сборка и запуск из папки проекта:

```sh
make
./build/lab3
```

Порядок ввода: количество судов (1–50), координаты всех судов,
координаты трёх вершин треугольника, координаты порта.
Каждая точка: шесть целых чисел — градусы, минуты, секунды широты,
затем градусы, минуты, секунды долготы.
После первого результата нажимайте Enter для перехода к следующему судну.
Для звукового сигнала терминал должен поддерживать BEL.

Проверка на примере Валенсии:

```sh
./build/lab3 < tests/valencia.txt
```

Пустые строки в конце тестовых файлов заменяют нажатия Enter.
Проверка пяти наборов из таблиц 3.1–3.5 пособия и ошибок ввода:

```sh
python3 tests/check.py
```

В локальной сборке добавлен общий main, исправлены поиск максимального
углового коэффициента и условия повторного ввода координат. При ошибке
в координатах судов повторно вводится вся группа судов; при ошибке в
треугольнике — все три вершины. При EOF во время ввода программа завершается
с ошибкой. Имя danger_indification сохранено для совместимости с кодом команды.

Используется алгоритм сравнения угловых коэффициентов из пособия.
Он проверен на его пяти наборах данных, но не является универсальным
пересечением отрезка с треугольником: вертикальные направления, совпадение
точек и положение зоны за портом требуют отдельного геометрического решения.
